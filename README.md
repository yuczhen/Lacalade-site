# La Calade Site

Static website migrated from the original Weebly site and hosted on GitHub Pages.

## Structure

- `index.html` — Home page
- `about.html` — About page
- `games.html` — Games page
- `slots.html` — Slots page
- `news.html` — News page
- `article.html` — Article page
- `contact.html` — Contact page
- `survey.html` — Survey page
- `cca-2016.html` — Archived event/content page
- `apps/` — Application-related assets/content
- `files/` — Site files and downloadable assets
- `uploads/` — Images and uploaded media

## Hosting

This repository is published with GitHub Pages from the `main` branch.

## Migration

The current files were imported from the legacy Weebly export. The first goal is to restore the original site as closely as possible before making design or structural changes.
